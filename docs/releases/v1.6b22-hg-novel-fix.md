# i短剧 1.6b22 红果取流与小说详情页流畅度修复版

- **红果取流恢复（iOS + Android）**：同步最新 Medusa 签名兼容字段（顶层 `field 25` 非空兼容值），恢复匿名身份在 `/novel/player/multi_video_model/v1` 的连续取流（实网 6 集连测 `PPPPPP` 全部通过）。
- **小说详情页滑动卡顿修复（iOS）**：
  - 去掉每像素触发 `body` 重算的 `scrollY` 状态，改用阈值吸顶 `.compatOnScrolled(threshold: 210)`；
  - `actionsOut` 浮动栏状态切换增加变更守卫，避免每帧触发弹簧动画；
  - 离线已缓章节数改为单次目录扫描 + 后台线程异步计算，消除滑动时主线程同步 SHA256 与数千次磁盘 `stat()`；
  - 顶部模糊封面改用降采样 `CoverView(maxPixelSize: 320)`。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

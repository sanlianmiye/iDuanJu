# i短剧 1.6b23 iOS 锁屏恢复画音同步修复版

- **修复 iOS 锁屏/退后台返回后「只有声音、画面卡住 / 音画不同步」（#17）**：
  - `MPVPlayerEngine` 监听 `didEnterBackground` / `willEnterForeground` / `didBecomeActive` 生命周期（主播放器与 TVBox 播放器同时生效）；
  - 锁屏退后台前同步暂停并卸载 `vid`（释放 MoltenVK Metal swapchain 与 VideoToolbox 硬解会话），避免后台 GPU 限制导致画面卡死；
  - 解锁返回前台后重建视频输出、对点播片源执行精确 `seek` 对齐音画时钟并恢复播放。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

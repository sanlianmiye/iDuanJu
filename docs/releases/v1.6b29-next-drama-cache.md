# i短剧 1.6b29 双端播完连刷推荐、进度条缩略图预览、站源缓存与 iOS 扫码修复

### 双端新特性（合并 PR #25 并对齐 iOS）
- **播完连刷推荐（iOS + Android）**：
  - 3 级瀑布流推荐（同系列下一季 → 同分类/同标签热门 Top 8 → 通用热门），自动过滤已看与本次跳过的剧；
  - 播完大结局弹出 3 秒倒计时推荐卡片，支持「立即播放」「换一部」「取消」，可在「更多」中随时开关；Android 大结局上滑亦可直接滑出下一部推荐。
- **进度条拖动缩略图预览（Android 合并 PR #25，对齐 iOS）**：
  - 横竖屏拖动进度条时拇指上方浮出对应画面缩略图 + 实时时间戳与相对偏移，自适应横/竖屏比例，HLS 自动优雅降级。

### 体验修复
- **Android 站源/插件内存缓存与下拉刷新**：从 CMS 站源、JS 插件或黄果点进详情再返回时直接复用缓存并保持选中分类与滚动位置，不再重复加载；列表顶部支持手动下拉刷新。
- **iOS 红果短剧扫码后台恢复修复**：后台 `WKWebView` 保持可见不透明层防止切回后定时器被 WebKit 冻结，并在 WebView 内直查 `/api/pc/profile` + 监听 `scenePhase == .active` + 增加手动检查登录按钮，切回 App 秒识别登录态。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

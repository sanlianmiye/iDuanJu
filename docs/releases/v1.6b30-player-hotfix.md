# i短剧 1.6b30 播放器热修（Android 黑屏无声修复 + iOS 无感切集优化）

### Android 热修
- **修复部分机型播放红果黑屏无声**：
  - 移除双并发 `ExoPlayer`（`standbyPlayer`）与第二个 `TextureView`，改为单 `ExoPlayer` + 后台异步首帧 `Bitmap` 无缝交接，彻底消除双硬解实例抢占解码器/音频焦点的问题；
  - `EpisodeCache` 首帧抽取改为后台异步执行，不再阻塞起播；
  - 仅在开启超分锐化或 SDR→HDR 时才挂载 `VideoFrameProcessor` GL 管线，默认播放走原生硬件直出，并恢复 `2s / 2.5s` 安全预缓存间隔。

### iOS 体验优化
- **切集无闪烁 & 去 Toast**：
  - 切集时保持当前播控显隐状态不变，不再强制弹出/闪烁底部进度条与播控栏，也不再清空 `tech` / `videoSize`；
  - 移除切集时的「第 X 集」Toast 弹窗；
  - 首帧交接增加 `90ms` 渲染缓冲（`revealedIndex`），等 `MPVMetalLayer` 送显第 0 帧后再揭开首帧图，消除切集瞬间黑闪。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

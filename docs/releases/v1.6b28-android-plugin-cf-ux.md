# i短剧 1.6b28 插件可见性修复、批量导入、起播缓冲提示与站点验证弹窗

### Android 修复与体验升级
- **修复 18+ 插件首页/搜索/我的页不显示的 Bug**：移除 `HomeScreen`、`SearchScreen`、`ProfileScreen` 中硬编码的 `visible(false)` / `!it.adult` 过滤，开启「片源管理 → 成人内容」后正常显示全部已启用 18+ 插件、黄果与真实插件计数。
- **新增可见 WebView 站点验证弹窗（对齐 iOS）**：插件声明 `permissions.cloudflare = true` 且遇到站点人机验证时，弹出全屏可见 WebView 让用户手动完成验证，点「完成」后自动同步会话 Cookie 与真实 `User-Agent` 并重试原请求。
- **播放器起播与缓冲转圈提示**：监听 ExoPlayer `STATE_BUFFERING` 与首帧渲染状态，超过 `280ms` 未出帧或中途缓冲时自动居中显示「正在加载视频…」/「正在缓冲…」，避免起播黑屏等待无反馈（不影响本地预缓存秒开）。
- **本地插件支持批量多选导入**：「从文件导入」升级为多选文件选择器，可一次选中多个 `.idjplugin` 批量导入并汇总结果。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

# i短剧 1.6b24 双端播放器增强与流畅度优化版

### Android
- **播放器画中画与增强设置（#19）**：支持系统画中画（PiP，含播放/暂停与下一集快捷操作）、新增「更多设置」面板（画面比例记忆、倍速记忆、定时关闭、自动连播）、新增 Media3 `GlEffect` AMD FidelityFX CAS 实时 GPU 锐化增强、`TextureView` 顺滑退出过渡。
- **Compose 流畅度优化（#18）**：详情页/首页吸顶与浮动栏改用 `derivedStateOf`，播放器进度条独立重组域，弹幕缓存 `TextMeasurer` 并预解析颜色，大幅减少无谓重组。
- **详情页演员可点击（#20）**：演员头像与兜底主演标签均可点击查看作品或聚合搜索。
- **合并后修复**：修复横屏直接退出时系统栏未恢复、首次进入播放器未自动应用持久化倍速的问题。

### iOS / iPadOS
- **同步播放器增强**：支持倍速偏好持久化、「更多」菜单新增 **画质增强（MPVKit 原生 GPU 锐化）** 与 **定时关闭（播完本集 / 15 / 30 / 60 分钟）**。
- **详情页演员/主演全可点击**：兜底主演改为可点击胶囊标签，无 ID 的演员头像也支持点击聚合搜索。

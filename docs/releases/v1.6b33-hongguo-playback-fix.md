# i短剧 1.6b33 红果取流修复（双端同步 · 协议配置可热更新 · iOS 新增 3 个片源）

> 💬 **交流群**：https://t.me/iduanjuapp ——使用问题、反馈与新版本通知欢迎进群。

### 修复：红果取流一直加载 / 无法播放（Android & iOS）
- **根因**：红果服务端自 11 月 23 日起拒绝旧版请求（返回 `HTTP 200` 空包），旧签名里 Medusa 的第 21 字段值 `377` 被判无效；同时旧的取流接口对匿名设备也不再返回播放信息。
- **取流链路更新**：改走 `7.4.5.32` 的 `preload/v1`（gzip 请求体，V5 三头签名，第 21 字段与真机一致），失败自动回退 `video_tab` 备用通道、`fallback_api` 编码协商（H.264 / HEVC）与网页兜底。
- **播放设备稳定**：新增 `tt-data=a` 匿名设备注册并持久化复用，不再每次取流都注册新设备；新设备未同步时自动等待重试，注册受限时回退基准设备；「我的 → 重置红果设备注册」会同时清理播放设备与取流缓存。
- **Android 补齐能力**：补上 `fallback_api` 编码协商（仅 ByteVC2 的剧集也能播）与 `key_seed` 地址解包，与 iOS 对齐。
- **iOS**：去掉取流 3 秒超时竞态，冷启动注册设备时不再提前放弃签名取流。

### 新增：红果协议配置可远程更新
- 取流用到的第 21 字段、请求参数、接口域名与路径、基准设备，改为读取仓库里的 `configs/hongguo-protocol.json`，App 启动后后台拉取（`raw` 与 jsDelivr 镜像），拉取失败或校验不通过时使用内置默认值。
- 域名仅允许 `fqnovel.com` / `snssdk.com`，文件大小与字段范围均有校验；上游再次调整这些参数时，无需发版即可恢复。

### iOS 新增片源（默认关闭）
- 片源管理新增 **YouPorn · RedTube · HQPorner** 三个长视频源，需在「片源管理」里手动开启，沿用 18+ 开关与标题安全过滤。

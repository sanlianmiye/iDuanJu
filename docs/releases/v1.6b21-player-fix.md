# i短剧 1.6b21 TVBox 播放与横竖屏切换修复版

- **TVBox 真机播放修复**：iOS 端 TVBox 直播与点播播放器由裸 `AVPlayer` 迁移至 `MPVPlayerEngine`（并支持自动回退 `AVPlayerEngine`），统一激活播放音频会话、解析 `url|User-Agent=...&Referer=...` 请求头与 `$` 后缀，增加缓冲与失败重试状态。
- **横竖屏旋转画面跳变修复**：禁用 `MPVMetalLayer` 与 `PlayerRenderHost` 旋转期间的 CoreAnimation 隐式位置/尺寸插值，消除切横竖屏时画面从左下角突然放大的跳变，缩短视频尺寸重排防抖延迟。
- **旋转解锁与内存安全**：修复 `Orientation.exitLandscape()` 误把解锁逻辑写入 `errorHandler` 的问题；修复 `MPVPlayerEngine.deinit` 在 `videoQueue` 上的潜在竞态。
- **缓存与会话优化**：`CoverImage` 按原始 URL 共享磁盘缓存与并发下载去重，避免同图多尺寸重复拉取；`HGStreamExtras` 复用静态 `URLSession`，消除每次请求的会话泄漏。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

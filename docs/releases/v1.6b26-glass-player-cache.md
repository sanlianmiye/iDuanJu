# i短剧 1.6b26 短剧无感预缓存、TVBox 全屏修复与 Android 液态玻璃升级版

### 双端短剧体验优化
- **短剧后台预缓存 & 无感切集（iOS + Android）**：
  - **iOS**：每集起播 350ms 后后台自动下载并解密下 2 集到本地磁盘（`EpisodePlaybackLoader` 并发去重，保留最近 12 集），加载圈增加 280ms 宽限延迟，命中缓存切集零闪屏、零加载圈；
  - **Android**：`EpisodeCache` 新增零延迟 `peek()` 本地命中检测，命中缓存直接无缝切换不清空画面，`PlayerView` 开启 `setKeepContentOnPlayerReset(true)` 消除黑屏闪烁，并提前至开播 1.2s 后连续预缓存下 2 集。

### Android 重点升级（精选合并 PR #22 + 修复 #24）
- **TVBox 全屏返回修复（#24）**：全屏自动隐藏/恢复系统栏，顶栏与底栏避开状态栏与挖孔区域，返回热区放大至 `40dp` 并支持系统返回键退出全屏。
- **液态玻璃 UI & 平板重构**：支持液态玻璃 / 磨砂玻璃切换与透明度调节、可滑动底部 Dock、平板横竖屏首页/详情重排。
- **播放器升级**：4 档无闪烁环境光、左亮度/右音量/中切集三区手势、重力自动旋转、`MediaSession` 系统通知栏播控、GPU 实时超分锐化与 SDR→HDR。
- **扫码登录与观看历史同步**：支持账号扫码登录与观看历史同步。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

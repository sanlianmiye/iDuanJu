# i短剧 1.6b27 无闪详情页、抖音式切集、插件封面修复与双端对齐

### 体验修复（iOS + Android）
- **详情页首帧零闪烁**：
  - **iOS**：`CoverStore` 新增线程安全同步内存查表，`CoverView` 首帧直接命中已缓存海报图，详情页背景关闭 `ShimmerBlock` 与不透明离屏合成，消除大白条闪屏；
  - **Android**：列表/搜索/首页点击卡片即缓存封面与标题，详情页背景 API 31+ 直接复用原 URL 命中 Coil 内存缓存，首帧即呈现海报扩散背景。
- **抖音式无缝切集（告别封面闪屏）**：
  - **Android**：新增独立预解码待命播放器（`standbyPlayer`）与独立 `TextureView` 舞台，提前把下一集真实第 0 帧解码到 GPU；上滑直接跟手展示下一集真实视频画面，松手切集无缝交接至主播放器首帧渲染，移除海报封面预览与氛围模式。
  - **iOS**：预缓存下 2 集后后台抽取各集真实视频第 0 帧，切集上滑与起播交接全程显示真实视频首帧，不再闪现剧集海报或黑屏。
- **Android 插件封面修复**：
  - Coil 全局拦截器为未带 UA 的图片请求补充手机 Chrome `User-Agent` 与 `Accept`，修复 Cloudflare 图床（如 `321AV`、`JAVDB` 等）封面 403/空白问题；
  - `PluginVideo` 补齐 `coverHeaders` → `idjimg://` 支持，与 iOS 保持一致。

### iOS 对齐 Android 新特性
- **红果短剧扫码登录 & 观看进度云同步**：新增 `HongguoWebAccount` 与 `HongguoLoginView`，支持二维码扫码登录、保存二维码到相册及自动同步观看进度到红果。
- **播放器 SDR 转 HDR**：基于 MPV `libplacebo` 接入 `inverse-tone-mapping` 与动态范围增强（原生 HDR / 杜比视界自动旁路）。
- **iPad 竖屏画报式详情页**：竖屏平板采用卡片式头图布局与每组 50 集分组，横竖屏均不再重复展示主操作按钮。

IPA 为未签名包，需要自行重签后安装。Android 包使用项目现有分发签名。

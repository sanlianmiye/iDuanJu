### 更新内容

- 修复 iOS 16 上点开黄果短剧播放加载即闪退的问题：将所有 HLS（含黄果 AES-128 加密流）统一路由至本地回环 HTTP 代理（`LocalHLSProxy`），并新增预解析密钥直出路由 `/<token>/k.key`，避免走 iOS 16 上易崩溃的 `AVAssetResourceLoaderDelegate` 自定义 scheme 与私有 header 路径。
- 加固 `HLSPlayback` 兜底路径：共享 `URLSession`、补充 `resourceLoader(_:didCancel:)` 取消在途任务，并确保 `finishLoading` 切回串行代理队列且先校验请求状态。
- 补充 HLS 帧率/时长浮点转整数的 `isFinite` 校验，移除黄果旧接口请求中的 URL 强制解包。
